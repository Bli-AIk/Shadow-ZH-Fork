## 类、实例和继承
---

如果您熟悉面向对象编程，您就会知道什么是类。这里也是同样的概念。

虽然类不是 Lua 的功能，但该语言使它们非常容易实现。但什么是“类”？

---

### 什么是类？

类是一个模板。它包含一组变量和函数。 **实例**是类的副本。它具有类的所有变量和函数，但可以更改它们而不影响类本身。


#### 汽车的例子

以汽车为例。假设汽车的概念是一个类别。
它有四个轮子、车窗、方向盘等。这就是汽车。
但世界上存在多种汽车（几乎 15 亿辆！），因此我们将它们称为实例。
它们都有共同点，但颜色可能不同，门的数量也不同，等等。

汽车的概念是一个类，每辆车都是该类的一个实例。在 Kristal 的编程中，我们会执行以下操作：

```lua
local Car, super = Class()

function Car:init()
    super.init(self)

    self.color = "red"
end

function Car:getWheelCount()
    return 4
end

function Car:setColor(color)
    self.color = color
end

return Car
```

创建该类的新实例就像调用 `Car()` 一样简单。当您创建新实例时，将调用 `init` 函数。这是您设置实例的位置。

`self`是一个特殊变量，它指的是实例本身。因此，设置 `self.color` 会设置*该实例*的颜色。

`super`也是一个特殊变量，它指的是**父类**。稍后我们会讨论父母和遗产。

```lua
local new_car = Car() -- creates a new instance of the car class, or more simply, creates a new car.

print(new_car:getWheelCount()) -- prints "4"
print(new_car.color) -- prints "red"

new_car:setColor("blue") -- sets the color of the car to blue
print(new_car.color) -- prints "blue"
```

我们只是将汽车的颜色更改为蓝色，但类本身仍然将颜色预定义为红色。 **记住，类就像模板。**

---

### 遗产

类可以有一个父类。这就是所谓的**继承**。子类*继承*父类的所有变量和函数，但也可以拥有自己的变量和函数。

假设我们想制造一辆赛车。它仍然是一辆汽车，但有扰流板和不同的颜色。我们可以创建一个名为 `Racecar` 的新类，它继承自 `Car`。

```lua
local Racecar, super = Class(Car)

return Racecar
```

我们刚刚创建了另一个类，它是 `Car` 类的扩展。尽管上面的代码中没有任何函数，但它仍然具有 `Car` 类的所有函数：

```lua
local new_racecar = Racecar()
print(new_racecar:getWheelCount()) -- prints "4"
```

现在，还记得之前的 `super` 变量吗？如果我们重写父类的函数，我们可以用它来调用它们。

```lua
local Racecar, super = Class(Car)

function Racecar:init()
    super.init(self)

    self.color = "blue"
end

return Racecar
```

上面的示例调用父类`Car`的`init`函数，然后将赛车实例的颜色设置为蓝色。

**超级函数应该用句号调用，而不是冒号！他们还应该将 `self` 作为第一个参数！**

## 对象
---

物体是与 Kristal 交互的主要方式。他们是一个被吸引到屏幕上的类。他们有职位、等级制度和许多其他东西。

---
### 层次结构

这个词很难拼写，不是吗？

对象可以有子对象。这些孩子是相对于他们的父母而言的。如果您移动父级，子级也会随之移动。

对象的父对象绘制其子对象。这些孩子画“他们的”孩子，等等。家长们也会更新孩子的情况。我们稍后会讨论绘图和更新。

把它想象成一棵树。父母是树干，孩子是树枝。如果移动树干，树枝也会随之移动。

这些孩子——树枝——可以有自己的孩子——叶子。如果移动树干，树枝就会随之移动，叶子也会随着树枝移动。

这意味着**每个对象都有一个父对象**。唯一的例外是舞台。

---
### 舞台

阶段是层次结构的根。这是树的顶部。这是与树干相连的树根。

舞台是一个特殊的物体。它是唯一没有父对象的对象。它是一切的开始——它是第一个被绘制和更新的对象，它绘制和更新它的子对象，它绘制和更新它们的子对象，等等。

---
### 更新和绘图

对象有一些非常重要的功能。最重要的是 `update` 和 `draw`。

每帧都会调用更新，因此您可以在其中放置需要每帧运行的代码。很简单，对吧？您可以在其中在屏幕上移动某些内容，或者检查是否按下了按钮，或者需要每帧完成的任何其他操作。

Draw 也被称为每一帧。这是您实际将内容渲染到屏幕上的地方！您可以绘制图像、形状、文本等。
