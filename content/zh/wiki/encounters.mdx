# 遭遇战（Encounters）

<Box>

每场战斗都对应一次**遭遇战（Encounter）**。无论是一组怪物、一个 Boss，还是单个怪物，都可以组成一次遭遇战。Undertale 和 Deltarune 都使用这一系统，我们也会如此。

</Box>

<Box>
## 遭遇战基础
---

要开始创建遭遇战，你需要在 `encounters` 文件夹中新建一个文件。下面来制作一个只包含单个怪物的遭遇战，使用之前制作的 Dummy 敌人。

```lua
local Dummy, super = Class(Encounter)

function Dummy:init()
    super.init(self)

    -- Text displayed at the bottom of the screen at the start of the encounter
    self.text = "* The tutorial begins...?"

    -- Battle music ("battle" is rude buster)
    self.music = "battle"
    -- Enables the purple grid battle background
    self.background = true

    -- Add the dummy enemy to the encounter
    self:addEnemy("dummy")

    --- Uncomment this line to add another!
    --self:addEnemy("dummy")
end

return Dummy
```

好那么好——我们搞定啦。

</Box>

<Box>
## 高级遭遇战
---

不过，有些遭遇战会复杂一些。例如，如果你想在没有背景时也隐藏世界，可以将 `self.hide_world` 设置为 true。战斗也可以通过设置 `self.no_end_message = true` 来跳过“YOU WON!”提示。

遭遇战还拥有很多回调函数，你可以[在这里](/wiki/api/Encounter)阅读相关内容。

</Box>
