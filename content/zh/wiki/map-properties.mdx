# 地图属性

<Box>

地图有一些可以添加的自定义属性。

可以从顶部功能区进入地图的属性面板，路径是 **“Map” > “Map properties...”**。

下面列出了所有可以添加到地图的自定义属性。关于自定义属性的命名规则，请阅读此[教程](/wiki/using-events/#the-basics)：

    - `name: string` -> 地图的名称。主要用于在保存和加载游戏时显示当前所在的地图。
    - `music: string` -> 在此地图中播放的背景音乐名称。
    如果音乐名称与玩家之前所在地图中的音乐相同，音乐会继续播放，而不会重新开始。
    - `keepmusic: boolean = false` -> 如果为 **true**，Kristal 不会更改上一张地图的音乐，即使音乐曲目不同。
    <br></br>如果为 **false**，只有在音乐曲目不同时，Kristal 才会将上一张地图的音乐切换为此地图的音乐。
    - `light: boolean = false` -> 如果为 **true**，地图将处于 `light world`（光明世界），Kristal 会使用 Undertale 的物品栏、文本框和 Game Over 系统。如果队伍中的任何成员拥有光明世界版本，
    就会使用该版本，而不是普通的黑暗世界版本。
    <br></br>如果为 **false**，地图将处于 `dark world`（黑暗世界），Kristal 会使用 Deltarune 中的系统。
    - `border: string` -> 当玩家将 Kristal 的 `Border` 选项改为 `Dynamic` 时，要使用的边框名称。
    Kristal 已经定义了一些可以使用的边框：`castle`、`city`、`cyber`、`leaves`、`mansion` 和 `simple`，
    它们存放在 Kristal 源代码的 `assets/sprites/borders` 中。

</Box>
