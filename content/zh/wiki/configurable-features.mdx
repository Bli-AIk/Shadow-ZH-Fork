# 可配置的功能

<Box className={styles.table}>

<>![](/wiki/feature_config.png)</>

每个配置选项默认为当前章节中的值。
例如，DELTARUNE 第 1 章默认禁用存储，第 2 章默认启用存储。

你可以通过功能配置菜单单独更改每项功能。

| 配置项 | 说明 | 第 1 章 | 第 2 章 |
| --- | --- | --- | --- |
| `enableStorage` | 额外 48 格物品栏 | 否 | 是 |
| `smallSaveMenu` | 不含仓库/招募选项的单文件存档菜单 | 是 | 否 |
| `partyActions` | X-Actions 是否默认显示在法术菜单中 | 否 | 是 |
| `growStronger` | 用暴力击败敌人后提升属性 | 否 | 是 |
| `growStrongerChara` | 会在队伍中变强的角色 | 未设置 | "noelle" |
| `susieStyle` | Susie 使用的精灵图组 | 1 | 2 |
| `ralseiStyle` | Ralsei 使用的精灵图组 | 1 | 2 |
| `oldTensionBar` | 张力条是否使用方角 | 是 | 否 |
| `oldUIPositions` | 是否使用第 1 章的 UI 位置 | 是 | 否 |
| `oldGameOver` | 是否使用第 1 章的 Game Over 界面 | 是 | 否 |
| `targetSystem` | 战斗是否使用瞄准系统 | 是 | 否 |
| `speechBubble` | 敌人对话气泡的默认样式 | "圆形" | "赛博" |
| `enemyAuras` | 敌人周围的红色光环 | 否 | 是 |
| `mercyMessages` | 敌人的怜悯度提升时是否显示 +X% | 否 | 是 |
| `mercyBar` | 是否显示怜悯条 | 否 | 是 |
| `enemyBarPercentages` | HP 和怜悯条是否显示百分比 | 否 | 是 |
| `prioritySpareableText` | 敌人的可饶恕文本是否优先于疲劳/低生命值文本 | 是 | 否 |
| `pushBlockInputLock` | 推动方块时是否会锁定玩家输入 | 是 | 是 |
| `keepTensionAfterBattle` | 战斗后是否保留 TP，而不是重置 | 否 | 否 |
| `overworldSpells` | 法术是否可在主世界使用 | 是 | 否 |
| `damageUnderflowFix` | 禁用后，负数伤害会治疗敌人 | 是 | 是 |
| `darkCurrency` | 暗世界的货币全名 | "黑暗币" | "黑暗币" |
| `darkCurrencyShort` | 暗世界的货币简称 | "D$" | "D$" |
| `lightCurrency` | 光世界的货币全名 | "Money" | "Money" |
| `lightCurrencyShort` | 光世界的货币简称 | "$" | "$" |
| `tpName` | 战斗中的张力点名称 | "TP" | "TP" |
