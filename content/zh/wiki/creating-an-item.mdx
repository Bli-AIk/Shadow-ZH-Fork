# 创建物品

<Box>

你有没有遇到过这种情况？你正在制作商店，却突然发现自己没有任何可以出售的物品！这很常见，对吧？什么，你说现在还没有商店教程……？

制作物品主要就是复制粘贴，然后修改几个值。过程并不难，但如果要制作大量物品，可能会有点烦琐。

</Box>

<Box>
## 基础物品
---

假设你想制作一个除了占用库存空间之外什么也不做的物品。只需要在 `data/items` 中新建一个 Lua 文件。

下面是一个物品示例。它毫无用处，但确实是一个物品。

```lua
local item, super = Class(Item, "useless_item")

function item:init()
    super.init(self)

    -- Display name
    self.name = "Useless Item"
    -- Name displayed when used in battle (optional)
    self.use_name = nil

    -- Item type (item, key, weapon, armor)
    self.type = "item"
    -- Item icon (for equipment)
    self.icon = nil
    -- Whether this item is for the light world
    self.light = false

    -- Battle description
    self.effect = "Useless"
    -- Shop description
    self.shop = "Useless"
    -- Menu description
    self.description = "This item is useless"
    -- Light world check text
    self.check = "It's useless"

    -- Default shop price (sell price is halved)
    self.price = 0
    -- Whether the item can be sold
    self.can_sell = false

    -- Consumable target mode (ally, party, enemy, enemies, or none)
    self.target = "none"
    -- Where this item can be used (world, battle, all, or none)
    self.usable_in = "none"
end

return item
```

看到了吧，就是修改一堆变量。不过，如果我们希望它真的做点什么呢？这就要用到 `self.target` 和 `self.usable_in` 了。

---

### `self.target`

`self.target` 决定物品可以对谁使用。它可以是以下值之一：
- `ally`：选择一名盟友使用物品
- `party`：对整个队伍使用物品
- `enemy`：选择一名敌人使用物品
- `enemies`：对所有敌人使用物品
- `none`：没有目标，直接使用物品

---

### `self.usable_in`

`self.usable_in` 决定物品可以在哪里使用。它可以是以下值之一：
- `world`：可以在主世界中使用
- `battle`：可以在战斗中使用
- `all`：在哪里都可以使用
- `none`：无法使用

---

### 让它做点什么

让我们把它改成可以在主世界中使用。这很简单，只要把 `self.usable_in` 改成 `"world"`。我们还应该让玩家选择一名盟友来使用它，所以把 `self.target` 改成 `"ally"`。

```lua
function item:onWorldUse(target)
    return false
end
```

这是你在主世界中使用物品时会被调用的函数。它接收一个参数 `target`，也就是你选择的目标。

那么，来让它把人炸飞吧。这就是我希望玩家选择目标的原因。

```lua
function item:onWorldUse(target)
    local character = Game.world:getPartyCharacter(target)
    if character then
        character:explode()
    end
    return false
end
```

如果你给自己这个物品，然后试着对某个人使用，他就会爆炸！很完美，对吧？

等等——我们究竟要**怎么**获得这个物品？

### 给予物品

有很多种给自己物品的方法，比如商店和宝箱！但大多数时候，你会想使用 `Game.inventory:tryGiveItem(item)` 函数，从任何地方给予物品。

正如其名称所示，这是一个很棒的函数：它会尝试给予我们一个物品，并处理无法给予的情况。毕竟，玩家可能已经囤了 48 杯腐烂的茶。

所以，要发放这个厉害的物品，我们可以从其他代码（例如过场动画）中运行这样的代码：

```lua
local success, result_text = Game.inventory:tryGiveItem("useless_item") -- This gives out our item to the player

cutscene:text(result_text) -- This displays the "You got the ..." and "ITEM was added to your STORAGE" texts or "You already have too many ITEMs" which are generated by us from tryGiveItem.
```

等等！这不是过场动画教程……肯定有更简单的方法来测试我们的物品吧？

你很幸运！因为 Kristal 里还有一个***调试菜单***，它也能给予我们物品。

只需按下 `` Shift + ` ``（在某些键盘上也可能需要按 `` Shift + ~ ``）。这时应该会出现 KRISTAL DEBUG 菜单。

在菜单中找到 `Give Item` 选项——这就是我们要找的。然后搜索 `useless_item` 并选中它。你会听到一声提示音，这个物品现在应该已经在你的库存里了！

## 治疗物品
---

治疗物品很简单，只要改为继承 `HealItem` 即可。

你需要将 `self.heal_amount` 设置为希望物品为使用者恢复的数值。除此之外……没有其他区别了。很方便吧。
</Box>

<Box>
## TP 物品
---

TP 物品也很简单，只要改为继承 `TensionItem` 即可。

你需要设置想要获得的 TP 数量 `self.tp_amount`。
</Box>

## 防具
---

以下是白色缎带中的所有特殊设置：

```lua
self.type = "armor"
self.icon = "ui/menu/icon/armor"
-- Equip bonuses (for weapons and armor)
self.bonuses = {
    defense = 2
}
-- Bonus name and icon (displayed in equip menu)
self.bonus_name = "Cuteness"
self.bonus_icon = "ui/menu/icon/up"

-- Equippable characters (default true for armors, false for weapons)
self.can_equip = {
    susie = false
}
```

`bonuses` 是一个简单的表，可以使用 `defense`、`magic` 和 `attack`，这些键都是可选的。
</Box>

## 武器
---

下面是 EverybodyWeapon（一件未使用的武器）中的代码：

```lua
self.type = "weapon"
self.icon = nil

-- Equip bonuses (for weapons and armor)
self.bonuses = {
    attack  = 12,
    defense = 6,
    magic   = 8,
}

-- No special bonus
self.bonus_name = nil
self.bonus_icon = nil

-- Everyone can equip
self.can_equip = {}
```

## 反应
---

当你使用或装备物品时，角色可能会做出反应。这通过 `self.reactions` 表实现。再次看看 EverybodyWeapon，我们会得到：

```lua
-- Character reactions
self.reactions = {
    susie = "Uhhh... Ok.",
    ralsei = "A perfect fit!",
    noelle = "Wh... what is this?",
}
```
