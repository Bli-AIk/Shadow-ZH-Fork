## 第一部分：基础
---

Lua 很容易入门，但很难精通。

---

### 字符串与第一个程序 [strings]

首先，让我们从一个非常、非常简单的程序开始：

```lua
print("Hello, World!")
```

在输入框中输入这段代码（如果那里还没有的话），然后点击顶部的绿色“Execute”按钮。你会在右侧的输出框中看到结果。
恭喜你，你已经写出了第一个 Lua 程序！

那么，这里发生了什么？让我们把它拆开来看。

- `print`：这是一个**函数**名。函数是一段用于“执行某个操作”的代码。在这个例子中，`print` 函数会把你传给它的内容写入输出区域。
- `"Hello, World!"`：这叫作**字符串**。字符串是一串字符，就像一句话。在这个例子中，它是我们想要“打印”的文本。字符串由引号标记。
- `()`：这是圆括号。它们用于“调用”（运行）函数，也用于向函数传入数据。在这里，我们给 `print` 传入了一个字符串，即 `"Hello, world!"`。
- `""`：这是引号，用于标记字符串。

字符串是 Lua 中非常重要的一部分。它们用于保存文本，可以保存从单个字母到整本书的任何内容。字符串非常、非常有用。

---

### 数字

```lua
print(5 + 10)
```

这会输出 `15`，因为 `5 + 10` 等于 `15`。Lua 会做数学运算！

这也引出了另一种数据类型：数字。数字就是数字。它们可以是整数，也可以是小数（带有小数点的数字）。Lua 可以对数字进行数学运算。

```lua
print(0.1 + 0.2)
```

这会输出 `0.3`。

---

### 变量

变量是 Lua 的另一个重要组成部分。变量用于保存数据。试试下面的代码：

```lua
local x = 5
print(x)
```

这会输出 `5`。这是因为我们把数字 `5` 保存到了变量 `x` 中，然后把它打印出来。

再来看一个例子：
    
```lua
local x = 5
local y = 10
print(x + y)
```

这会输出 `15`。这是因为我们把数字 `5` 保存到了变量 `x` 中，把数字 `10` 保存到了变量 `y` 中，然后打印出了 `x` 和 `y` 的和。

当然，字符串也可以这样使用！

```lua
local x = "Hello!"
print(x)
```

这会输出 `Hello!`。这是因为我们把字符串 `Hello!` 保存到了变量 `x` 中，然后把它打印出来。

但是，如果我们什么都不放进去会怎样？或者说，我们要怎么做到这一点？这就要用到 `nil` 了：

```lua
local x
print(x) -- 输出 nil

-- 或者 --

local x = 10
print(x) -- 输出 10
x = nil
print(x) -- 输出 nil
```

`nil` 表示不存在任何值。

---

### 局部变量

你可能注意到了，我们第一次设置变量时使用了“local”这个词。这是因为我们正在创建一个**局部变量**。

局部变量只能在它所在的“作用域”中访问。作用域就是一段代码。例如：

```lua
if condition then
    local hello = "Hello!"
end

print(hello)
```

这会输出 `nil`，因为 `hello` 是一个局部变量。
它只能在那个 `if` 语句内部访问，也就是说，`hello` 在语句外部并不存在。

这个例子使用了 `if`，稍后会介绍它。

---

### 全局变量

不使用 `local` 时得到的就是全局变量。全局变量可以从代码的任何位置访问，不受作用域限制。

**大多数时候，你不应该使用全局变量。** 应该尽可能避免它们，只在**不得不用**的时候使用。

**如果可以，请尽量让所有变量都成为局部变量。** 还有其他保存信息的地方（表），稍后你会学到它们。

---

### 注释

代码中应该到处都有注释。注释用于解释代码做了什么，以及它为什么这样做。注释也可以用来禁用代码。

```lua
print("Hello!")
-- print("Goodbye!")
```

这段代码**只会**输出 `Hello!`。这是因为第二行被注释掉了，也就是说解释器会忽略它。

注释由 `--` 标记。一行中 `--` 后面的所有内容都会被忽略。

你也可以让注释跨越多行：

```lua
--[[
这是一个注释。
它跨越了多行。
]]
```

---

### 字符串（续）

字符串实际上比目前看到的内容稍微复杂一些。例如，下面是一个有效的字符串：

```lua
[[
This is a string.
It spans multiple lines.
]]
```

它看起来很像多行注释，对吧？这是一个跨越多行的长字符串。我们不使用 `"`，而是使用 `[[` 和 `]]` 来标记多行字符串！

此外，你也可以使用 `'this'` 这样的字符串来代替 `"this"`。它们是同一种东西。

等等，如果有一个像 `"this"` 这样的字符串，要怎样把引号放进字符串里？可以使用 `\"` 将引号放入字符串。例如：

```lua
print("\"Hello!\"")
```

这会输出 `"Hello!"`。这是因为我们使用了 `\"` 将引号放进字符串。

如果我们想把两个字符串连接起来呢？可以使用 `..`：

```lua
print("Hello" .. " world!")
```

这会输出 `Hello world!`。当然，你也可以在字符串中使用变量：

```lua
local x = "Hello"
print(x .. " world!")
```

这同样会输出 `Hello world!`。

---
### 布尔值

条件是编程中非常重要的一部分。它们用于检查某件事是真还是假。例如：

```lua
if 5 > 10 then
    print("5 is greater than 10!")
end
```

这段代码不会输出任何内容，因为 `5 > 10` 是假的。`>` 是比较运算符，用于比较两个值，并返回真或假。在这里，`5 > 10` 为假，所以 `if` 语句中的代码不会运行。

那么布尔类型是怎么回事？很简单。`if <...> then` 之间的所有内容都会被求值，然后使用求值结果。

所以，单独计算 `5 > 10` 会得到 `false`！我们甚至可以把它保存到变量中：

```lua
local x = 5 > 10 -- 假
local x = false  -- 假
local x = true   -- 真
```

然后就可以在 `if` 语句中使用它：

```lua
local x = 5 > 10 -- 假
if x then
    print("5 is greater than 10!")
end
```

当然，这段代码什么也不会输出！

---

### 函数

函数用于保存一段代码，并在之后运行它。例如：

```lua
local function add(a, b)
    return a + b
end

print(add(5, 10))
```

这会输出 15，因为我们定义了一个名为 `add` 的函数，它接收两个参数 `a` 和 `b`，并返回 `a + b`。然后，我们用 `5` 和 `10` 调用了这个函数，并打印出结果。函数非常有用，它们可以让你复用代码，也能让代码更易读。

Lua 内置函数的列表非常庞大，没错，`print` 就是其中之一！我们一直都在使用函数。

和其他数据类型（比如字符串、数字等）一样，函数实际上也可以保存到变量中。

这和上面的例子完全相同：

```lua
local add = function(a, b)
    return a + b
end
```

像这样使用的函数叫作匿名函数。这是因为这个函数没有名字，而是被保存到了变量 `add` 中。

你甚至也可以把有名字的函数保存到变量中：

```lua
local function add(a, b)
    return a + b
end

local add2 = add
```

`add2` 和 `add` 完全相同！

---

### 表

表用于保存数据。可以把它们想象成一个值的列表。例如：

```lua
local x = {
    "One",
    "Two",
    "Three"
}
```

这会创建一个包含**三个项目**的表。第一个项目是 `"One"`，第二个项目是 `"Two"`，第三个项目是 `"Three"`。我们可以这样访问这些项目：

```lua
print(x[1])
```

对表使用 [index] 会返回该索引处的项目。在这个例子中，它会输出 `One`，因为第一个项目是 `"One"`。

我们也可以向表中添加项目：

```lua
table.insert(x, "Four")
```

这会把 `"Four"` 添加到表的末尾。现在，`x[4]` 就是 `"Four"`。

但要注意，超出表长度的任何位置都会返回 `nil`：

```lua
print(x[5]) -- nil
print(x[0]) -- nil
print(x[500]) -- nil
```

在变量前加上 `#`，就可以获取表的长度：

```lua
print(#x) -- 4
```

---

### 表（续）

表还可以拥有键。键用于访问表中的项目。

```lua
local x = {
    one = "One",
    two = "Two",
    three = "Three"
}
```

要访问这些项目，我们使用键：

```lua
print(x["one"])
```

这会输出 `One`，因为键 `one` 对应的值是 `"One"`。

我们也可以使用点运算符访问项目：

```lua
print(x.one)
```

这和 `x["one"]` 完全相同！你甚至可以把它们连起来：

```lua
local x = {
    one = {
        two = {
            three = "Three"
        }
    }
}
print(x.one.two.three)
```

这会输出 `Three`！

---

### 循环

循环用于重复执行代码。例如：

```lua
for i = 1, 10 do
    print(i)
end
```

这会输出从 1 到 10 的每个数字。这是因为 `for` 循环会将其中的代码重复执行 10 次。变量 `i` 用于记录循环已经运行了多少次。它从 1 开始，一直增加到 10。

如果我们想跳过每隔一个数字呢？可以使用 `step` 参数：

```lua
for i = 1, 10, 2 do
    print(i)
end
```

看到那个 2 了吗？它就是**步长**，表示每次循环中 `i` 增加多少。

我们也可以使用 `while` 循环：

```lua
local i = 1
while i <= 10 do
    print(i)
    i = i + 1
end
```

`while` 会一直循环，直到条件为假。它就像把 `for` 和 `if` 混在了一起！不过要小心，不要意外创建无限循环：

```lua
while true do
    print("Oh no!")
end
```

这个循环会永远运行，因为 `true` 永远都是真的！

### 综合运用

让我们编写一个程序，它接收一个数字表，并输出所有数字的总和：

```lua
local function sum(x)
    local total = 0
    for i = 1, #x do
        total = total + x[i]
    end
    return total
end

local x = { 1, 2, 3, 4, 5 }

print(sum(x))
```

我们来逐步分析：

- 首先，我们创建一个函数。这个函数接收一个数字表，并返回所有数字的总和。
- 在这个函数中，我们创建了一个名为 `total` 的变量，用于保存所有数字的总和。
- 我们使用 `for` 循环遍历表中的每一个数字。
- 我们把这个数字加到 `total` 中。
- 我们返回 `total`。
- 在函数外部，我们创建了一个数字表。
- 我们用这个表调用函数，并打印结果。

基础部分就到这里！内容还挺多的，对吧？别担心，它没有看上去那么复杂。至少目前还没有。

---

### 作用域与局部变量

我们一直在使用 `local` 关键字，到底是怎么回事？

`local` 用于让变量局限在某个作用域中。作用域就是一段代码。例如：

```lua
local x = 5

if true then
    local x = 10
    print(x)
end

print(x)
```

第一个 `x` 的作用域是整个程序。第二个 `x` 的作用域是 `if` 语句。这意味着第一个 `x` 不会受到第二个 `x` 的影响。

所以，输出结果如下：

```
10
5
```

作用域可以包含其他作用域。例如：

```lua
local x = 5

if true then
    print(x) -- 输出 5
    local y = 10
    print(y) -- 输出 10
end

print(y) -- 输出 nil，因为该变量在此作用域中不存在！
```

基础部分就到这里！现在你已经可以编写简单的程序，也知道如何使用变量、函数和表了。幸好这就是全部内容了，对吧？……对吧？

## 第二部分：进阶

我们已经介绍过表了，在上一部分甚至专门用了两个小节。它们应该没有更多内容了吧？

好吧，这里有一整部分都是专门讲表的。哎呀。

### 表（续再续）

你不必总是使用 `for` 循环和索引来遍历表，也可以使用 `ipairs`：

```lua
local x = {
    "One",
    "Two",
    "Three"
}

for index, value in ipairs(x) do
    print(index, value)
end
```

这会得到以下输出：

```lua
1	One
2	Two
3	Three
```

这正是我们想要的结果。`ipairs` 用于遍历表，并取得每个项目的索引和值。

如果你的表拥有键，可以使用 `pairs`：

```lua
local x = {
    one = "One",
    two = "Two",
    three = "Three"
}

for key, value in pairs(x) do
    print(key, value)
end
```

结果是：

```lua
two     Two
three   Three
one     One
```

这……很有意思。它们没有按顺序出现！这是因为表不保证以任何特定顺序排列。

由于类似列表的表具有这种特性，它们总会保持顺序。但拥有键的表不保证以任何特定顺序排列。

---

### 表中的函数

表可以保存函数。例如：

```lua
local x = {
    add = function(a, b)
        return a + b
    end,
    subtract = function(a, b)
        return a - b
    end
}
```

很简单，对吧？我们只需要像这样调用它们：

```lua
print(x.add(5, 10))
print(x.subtract(5, 10))
```

这会分别输出 `15` 和 `-5`。

---

### 类似类的表

由于 Lua 没有类系统，表本身就被用作类。例如：

```lua
local x = {
    name = "Bob",
    age = 10,
    sayHello = function(self)
        print("Hello, my name is " .. self.name .. "!")
    end
}

x:sayHello()
```

这会输出 `Hello, my name is Bob!`。不过冒号（`:`）是怎么回事？它用于把这个表作为第一个参数传给函数。这叫作语法糖，只是下面写法的简写：

```lua
x.sayHello(x)
```

这和上面的例子完全相同，只是一个简写。

---

### 可变参数、多返回值与解构

函数可以返回多个值。例如：

```lua
local function addAndSubtract(a, b)
    return a + b, a - b
end

local x, y = addAndSubtract(5, 10)
print(x, y)
```

这会输出 `15 -5`。这是因为函数返回了两个值：`a + b` 和 `a - b`。我们可以把这些值保存到两个变量 `x` 和 `y` 中，然后把它们打印出来。

但如果我们只想要其中一个值呢？可以使用 `_` 忽略这个值：

```lua
local x, _ = addAndSubtract(5, 10)
print(x)
```

这会输出 `15`。这是因为我们忽略了第二个值，只保存了第一个值。

（严格来说，它并没有被忽略，而是被保存到了名为 `_` 的变量中；`_` 只是一个变量名。这样写只是惯例。）

接下来是可变参数。可变参数用于向函数传入数量未知的参数。例如：

```lua
local function add(...)
    local total = 0
    for _, value in ipairs({...}) do
        total = total + value
    end
    return total
end

print(add(1, 2, 3, 4, 5))
```

这会输出 `15`。这是因为我们向函数传入了 5 个参数，而函数把它们全部加在了一起。

我们可以用以下方式使用 `...`：

```lua
-- 将所有参数传给另一个函数

local function test(...)
    print(...)
end

-- 将多个参数转换为一个表
local function test(...)
    local x = {...}
    print(x[1])
end

-- 对参数进行“解构”
local function test(...)
    local x, y, z = ...
    print(x, y, z)
end
```

解构就是取得最前面的几个参数，并忽略其余参数。我们之前其实已经进行过解构了，你注意到了吗？

```lua
local function addAndSubtract(a, b)
    return a + b, a - b
end

local x, y = addAndSubtract(5, 10)
print(x, y)
```

这里解构的是函数的返回值。我们取得前两个值，并忽略其余值。在这个例子中，函数只有两个返回值，所以我们取得了全部返回值。
