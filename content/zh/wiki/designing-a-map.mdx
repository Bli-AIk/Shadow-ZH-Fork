# 设计地图

<Box>

地图很复杂，其中充满了各种不同的内容。因此，我们需要一个强大的工具来设计地图。
这就是我们使用 [Tiled](https://www.mapeditor.org/) 的原因。

</Box>

<Box>

## 安装 Tiled
---

Tiled 支持所有主流平台。你可以从[这里](https://www.mapeditor.org/)下载它。目前还没有专门用于 Kristal 的 Tiled 扩展，所以完成这一步就够了。

</Box>

<Box>

## 打开项目
---

安装 Tiled 后，就可以打开项目了。点击 `File`，然后选择 `Open File or Project`。

<>![](/wiki/designing-a-map/tiled_open.png)</>

接着进入你的项目文件夹。你应该能找到名为 `<your-project>.tiled-project` 的文件。打开它。

现在，左侧的项目窗口应该会显示一个文件夹树。这就是你的项目。双击任何地图即可打开！你可以随意查看和修改它们！

</Box>

<Box>
## 创建图块集
---

这些是默认的地图和图块集。

<>![](/wiki/designing-a-map/maps.png)</>

现在什么都没有！这正是开始的完美状态。

首先，我们需要创建一个图块集。顾名思义，图块集就是一组图块。每张地图都由图块组成！我们就使用下面这个：

<ScaledSprite src="/wiki/example_tileset.png" name="example_tileset.png" width={120} height={80} scale={2}/>

它……算不上最好的图块集，但够用了。将它保存到 `assets/sprites/tilesets` 文件夹，并命名为 `example_tileset.png`。**图块集图片必须使用这个目录，这一点非常重要。**

现在来创建图块集。

<>![](/wiki/designing-a-map/new_tileset.png)</>

将它命名为 `example_tileset`。图块宽度和高度应为 `20`，边距和间距应为 `0`。点击浏览，找到刚才保存的图块集图片。设置完成后应该如下所示：

<>![](/wiki/designing-a-map/new_tileset_filled.png)</>

点击 **Save As...**，将其保存到 `scripts/world/tilesets`，文件名为 `example_tileset.tsx`。**图块集也必须使用这个目录，这一点同样非常重要。**

图块集创建完成后，还差最后一步。打开图块集属性。

<>![](/wiki/designing-a-map/tileset_properties.png)</>

将 **Tile Render Size** 改为 `Map Grid Size`。这样图块就会按照我们需要的尺寸渲染。现在点击 **Save**。

保存所有内容后，按下 `CTRL+E` 来**导出**图块集。每次修改图块集后都必须重新导出，否则修改不会生效。

确保将它作为 `.lua` 文件导出到与 `.tsx` 文件相同的目录。也就是说，在本例中应为 `scripts/world/tilesets/example_tileset.lua`。

如果你厌倦了每次保存后都手动导出，可以在首选项中启用自动导出：

<>![](/wiki/designing-a-map/preferences.png)</>

总之，我们现在已经有图块集了！接下来为什么不创建一张地图呢？
</Box>

<Box>
## 创建地图
---

有趣的部分开始了。

依次点击 `File`、`New`、`New Map...` 来创建新地图。确保方向为 `Orthogonal`，
图层格式为 `CSV`，图块渲染顺序为 `Right Down`。

同时，将图块大小设置为 `40x40`。
你会注意到，这正好是图块集中图块大小的**两倍**。
这是因为 DELTARUNE 实际上会将图块放大 2 倍！既然我们不想手动放大，就交给 Tiled 来完成吧！

地图大小应设为 **Fixed**，宽度为 `16`，高度为 `12`。
这是地图的最小尺寸，因为它正好是屏幕的大小。
地图当然可以更大，但在本教程中，我们就使用 16x12。

点击确定后，你应该会进入一张空地图。
首先要做的是将它保存到项目中。
依次点击 `File`、`Save As...`，将它保存到 `scripts/world/maps`，文件名为 `example_map.tmx`。
**地图必须使用这个目录，这一点非常重要。** 你现在应该已经明白了。

现在可以放置图块了！随意制作你喜欢的内容，并且别忘了经常保存！这是我制作的地图：

<>![](/wiki/designing-a-map/example_map.png)</>

它……是一根巨大的骨头？我也不知道。这并不重要。重要的是保存地图，并且确保你对它感到满意。

</Box>

## 图层
---

Kristal 需要知道你打算如何使用每个图层。

Tiled 本身提供几种图层类型，其中最重要的是图块图层和对象图层。

图块图层可以直接使用，但 Kristal 中的对象图层需要标记为特定类型。

阅读[地图图层](/wiki/map-layers)页面，了解不同图层类型以及如何设置它们。

</Box>

<Box>
## 标记点
---

标记点是地图中非常重要的一部分。
它们用于标记出生点等位置，也可以标记一般的兴趣点。
让我们在地图中添加一个标记点。

首先，需要创建一个名为 `markers` 的新图层。

<>![](/wiki/designing-a-map/new_object_layer.png)</>

我们 Kristal 开发者很喜欢把它们设为紫色（这样一眼就能认出这个图层），但你也可以使用任何想要的颜色。

<>![](/wiki/designing-a-map/purple_color.png)</>

要放置一个点，请使用 Insert Point 工具。你可以在顶部工具栏中找到它，也可以按下 `I`。

<>![](/wiki/designing-a-map/insert_point.png)</>

现在点击地图上的任意位置。一个点应该会出现。
这就是标记点！我们现在要把它做成玩家的出生点，所以将它命名为 `spawn`。

<>![](/wiki/designing-a-map/example_map_with_spawn_marker.png)</>

现在在游戏中测试一下！保存地图，然后按下 `CTRL+E` 将其导出。
没错，地图也需要导出。记得要导出为 `.lua` 文件！

现在在 Kristal 中打开你的项目。你可能会进入这里……

<>![](/wiki/designing-a-map/room1.png)</>

……也可能遇到这个错误。

<>![](/wiki/designing-a-map/room1_error.png)</>

Kristal 当前正在尝试加载名为 `room1` 的地图。如果出现错误，说明你已经删除了它。没关系，因为我们并不需要它。

告诉 Kristal 改为加载我们的地图：

在 `mod.json` 中，将 `"map": "room1"` 改为 `"map": "example_map"`。
现在保存文件，再试一次。应该可以正常运行！看，我们的出生点也正常工作了！

<>![](/wiki/designing-a-map/working_spawnpoint.png)</>

</Box>

## 碰撞
---

我们的测试地图很完美，对吧？嗯……

<>![](/wiki/designing-a-map/outside_map.png)</>

……这可不对。我们没有添加任何碰撞！来修复它吧。

首先，需要再创建一个对象图层。将它命名为 `collision`。我们喜欢把这些图层设为蓝色！

<>![](/wiki/designing-a-map/blue_color.png)</>

现在选择 **Insert Rectangle** 工具。你可以在顶部工具栏中找到它，也可以按下 `R`。

<>![](/wiki/designing-a-map/insert_rectangle.png)</>

这是你用来绘制碰撞区域的工具之一。它很简单，只要点击并拖动来创建矩形即可。**记得按住 `CTRL`，让它吸附到网格！**

<>![](/wiki/designing-a-map/added_collision.png)</>

现在我们已经画出了碰撞区域，导出并测试一下吧！看，它能正常工作了！

---

### 斜坡、多边形及更多内容

使用 **Insert Polygon** 工具（你可以在顶部工具栏中找到它，也可以按下 `P`），
你可以创建任意多边形！无论是三角形、梯形，还是五边形，都可以制作！

按住 `CTRL` 同样可以让图形吸附到网格，从而制作出完美的形状！

## 事件
---

    事件是地图中非常重要的一部分。它们是可以直接放置在地图中的特殊[对象](/wiki/basics#objects)。

    ---

    ### 使用事件

    要使用事件，首先需要为它们创建一个图层。新建一个对象图层，并将它命名为 `objects`。我们会把这些图层设为粉色！

    <>![](/wiki/pink_color.png)</>

    现在可以选择前面提到的 **Insert Point** 工具。在地图上的任意位置点击，一个点应该会出现。这就是一个事件！或者说，它*将会*成为事件。

    将它命名为 `chest`。这会告诉引擎要使用哪个事件，在本例中是 [TreasureChest](/wiki/api/TreasureChest) 事件。现在给它添加一些属性。

    添加 `money` 自定义属性（确保类型是 `int`），并将其设置为 `999`。这样打开宝箱时，我们就能获得一大笔钱！

    <>![](/wiki/chest_properties.png)</>

    如果保存、导出，然后在 Kristal 中打开项目，就应该能看到宝箱了！与它互动还会获得 **999 黑暗币**！哇！

    ---

    ### 使用事件（续）

    好了，我们可以添加宝箱。但如果想添加一个不只是点、还需要更多内容的对象呢？这时可以使用 **Insert Rectangle** 工具来创建矩形！

    让我们制作一个可交互的方框。将它命名为 `interactable`，并添加一个字符串属性 `text`，内容设为 `* Hello, World!`

    <>![](/wiki/map_with_interactable.png)</>

    如果我们在游戏中查看它，那么……

    <>![](/wiki/hello_world_interactable.png)</>

    完美！

    ---

    ### 房间转换

    房间转换也是事件，因此上一节的内容同样适用于它们。

    它们的名称是 `transition`，可以使用以下属性，所有属性都是可选的：

    - `map` -> 要转换到的地图
    - `shop` -> 要转换到的商店
    - `x` -> 出生位置的 X 坐标
    - `y` -> 出生位置的 Y 坐标
    - `marker` -> 出生位置的标记点
    - `facing` -> 在地图中出生时面向的方向
    - `stairs` -> 是否播放楼梯音效

    大多数时候，你应该使用 `marker` 属性，而不是指定 `x` 和 `y`。

    ---

    ### 创建事件

    事件只是[对象](/wiki/basics#objects)，它们扩展了 [Event](/wiki/api/Event) 类。你可以在 `scripts/world/events` 中创建新文件并扩展 `Event` 类，来制作自己的事件。让我们制作一个风车事件！并让它在交互时旋转！

    下面是我制作的图片，虽然它们不是很好看：

    <ScaledSprite src="/wiki/pinwheel.png" name="pinwheel.png" width={12} height={12}/>
    <ScaledSprite src="/wiki/pinwheel_base.png" name="pinwheel_base.png" width={20} height={20}/>

    这是我最终写出的代码：

    ```lua
    -- Extend the Event class, and set the ID to "pinwheel"
    -- This is what you'll use to refer to the event in Tiled
    local PinwheelEvent, super = Class(Event, "pinwheel")

    -- `data` is the data directly from Tiled
    function PinwheelEvent:init(data)
        -- Place the event at the correct position, and make the size 20x20
        super.init(self, data.x, data.y, 20, 20, data)

        -- Any custom properties are stored in `data.properties`, but we don't use any.

        -- Just some variables for the pinwheel
        self.min_speed = 2
        self.speed_slowdown = 0.5
        self.speed = self.min_speed
        self.pinwheel_rotation = 0

        -- Most events in DELTARUNE are 2x sized
        self:setScale(2)

        -- We placed a single point in Tiled, which we want to be the bottom center of the pinwheel
        self:setOrigin(0.5, 1)
    end

    -- Update gets called every frame
    function PinwheelEvent:update()
        super.update(self)

        -- Make it rotate using the speed
        self.pinwheel_rotation = self.pinwheel_rotation + (self.speed * DTMULT)

        -- If it's going too fast, slow it down
        if self.speed > self.min_speed then
            self.speed = self.speed - self.speed_slowdown * DTMULT
        end

        -- Make sure it doesn't go below the minimum speed
        self.speed = math.max(self.speed, self.min_speed)
    end

    function PinwheelEvent:draw()
        super.draw(self)

        -- First, draw the base
        love.graphics.draw(Assets.getTexture("pinwheel_base"), 0, 0, 0, 1, 1)
        -- Then draw the pinwheel, spinning
        love.graphics.draw(Assets.getTexture("pinwheel"), 10, 10, math.rad(self.pinwheel_rotation), 1, 1, 6, 6)
    end

    -- When we interact with the pinwheel, make it spin faster!
    function PinwheelEvent:onInteract()
        self.speed = 60
    end

    return PinwheelEvent
    ```

    然后，我们只需要使用代码中提供的 ID `pinwheel`，把它放到某个位置！

    <>![](/wiki/pinwheel_placed.png)</>

    这样一来，我们就拥有了自己的事件！

    <>![](/wiki/pinwheel_spin.gif)</>

    ---

    ### 其他引擎事件

    Kristal 还直接在引擎中内置了许多其他事件。

    前往[使用事件](/wiki/using-events)，了解 Kristal 所有的事件。

    它们全部扩展自 [Event](/wiki/api/Event) 类或 [Character](/wiki/api/Character) 类。在 [API 参考](/wiki/api) 中使用树状视图并查找 `Character` 和 `Event`，就可以看到它们全部。
